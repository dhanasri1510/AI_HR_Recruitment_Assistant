# AI HR Recruitment Assistant 🤖

## 📌 Project Overview

AI HR Recruitment Assistant is an AI-powered application designed to help recruiters analyze candidate resumes and compare them with job requirements.

The system identifies matching skills, missing skills, provides a candidate match score, and generates relevant interview questions.

## 🎯 Objectives

- Analyze candidate resumes
- Compare resumes with job descriptions
- Identify matching and missing skills
- Generate a candidate match score
- Recommend whether a candidate is suitable for an interview
- Generate interview questions automatically

## ✨ Key Features

- 📄 Resume Analysis
- 🔍 Skill Matching
- 📊 Candidate Match Score
- ❌ Missing Skill Identification
- 💬 AI-Generated Interview Questions
- 🤖 AI-based Recruitment Assistance

## 🛠️ Technologies Used

- Python
- Artificial Intelligence
- RAG (Retrieval-Augmented Generation)
- AI Agents
- Tools
- Natural Language Processing

## ⚙️ How It Works

1. Enter the job description.
2. Provide the candidate's resume.
3. The system analyzes the resume.
4. Candidate skills are compared with job requirements.
5. A match score is generated.
6. Matching and missing skills are displayed.
7. Relevant interview questions are generated.
